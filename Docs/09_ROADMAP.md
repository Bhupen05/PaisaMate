# Product Roadmap

## MVP

### Personal
- Daily expenses.
- Product title and price.
- Need / Want / Dream.
- Categories.
- Monthly dashboard.

### Friends
- Friend management.
- Shared expenses.
- Equal/custom/percentage splitting.
- Balances.
- Settlements.

### Recurring
- Monthly maintenance expenses.
- Upcoming recurring view.
- Pause/resume.

## Version 1.1

- CSV export.
- Monthly reports.
- Better analytics.
- Expense search.
- Advanced filters.
- Notification preferences.

## Version 1.2

- Group-based shared expenses.
- Multiple recurring schedules.
- Settlement suggestions.
- Budget limits.
- Savings goals.

## Later

- Multi-currency.
- Receipt scanning.
- Bank transaction import.
- Advanced financial insights.
- Shared household spaces.

Do not implement later-stage features before the MVP data model can support them cleanly.
